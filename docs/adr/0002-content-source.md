# ADR 0002: Content source

Status: pending provider selection; adapter boundary accepted  
Decision owner: editorial lead and engineering lead  
Decision deadline: before production editorial migration

The implementation uses schema-validated fixtures behind a content repository module. A production CMS must support draft preview, scheduled publishing, homepage composition, typed relationships, correction history, media rights, audit roles, webhooks and exportable stable IDs.

No CMS vendor is embedded in page components. Provider selection requires an editor trial using one policy article, one correction, one contributor and one programmed homepage package.
