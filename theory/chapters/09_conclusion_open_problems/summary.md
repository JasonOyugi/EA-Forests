# Chapter 9 summary - What the framework gives us, and what remains open

The paper's conclusion is that the natural state of a forestry market is
measure-valued. Growth moves mass through tree size and quality space; mortality
and harvest remove standing-tree mass; bucking creates a heterogeneous log
measure; processor specifications define admissible regions of log space;
operators and distance determine delivered costs; and allocation is a partial
transport problem over those resources.

Because this state is only partially observed, the operational decision state is
a posterior over both the physical system and its unknown structural parameters.
This posterior links sensing, experiments, market exposure, contracting, and
regime changes through sequential control.

The framework's main value is separation. Biological productivity is not the
same as harvestable log supply. Harvestable supply is not the same as processor
compatibility. Compatibility is not the same as delivered surplus. Delivered
surplus is not the same as negotiated forest-gate price. Mapped area is not the
same as information value.

Each arrow between these objects is an operator that can be estimated,
validated, replaced, and improved as data arrive. This gives EA Forests a clear
research architecture: new evidence has a defined mathematical destination
rather than simply being added as another dashboard field.

The current East African numerical model is therefore a reduced-order projection
of a richer research target. The most important next work is not to add more
mathematics for its own sake, but to identify the operators that currently rely
on priors: mature growth and quality transition, tree-to-log recovery,
processor acceptance, contractor cost, outside options, adoption, and the value
of new observations.

The open problems folder treats these gaps as a research agenda. Some are
mathematical, some statistical, and some operational. The common test is whether
solving them changes a decision or materially improves calibration of a
structural operator.
